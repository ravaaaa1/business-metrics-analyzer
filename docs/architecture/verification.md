# Проверка архитектурных требований
Ниже план испытаний будущей веб-версии. Выполнение документации и демонстрационного Python-кода не означает прохождения испытаний приложения.

| Требование | Проверка | Критерий |
|---|---|---|
| BR-02, AC-01.1 | sample_sales.csv, октябрь 2026 | 30 000 RUB, 10 000 RUB/чек, 75%, 30% |
| AC-01.2 | Нет closed-сделок, нулевая выручка | R=0, отсутствующие отношения null, UI «Нет данных» |
| BR-03 | Менеджер A запрашивает B через URL, JSON, export ID и cache | Ни одна ветка не раскрывает B |
| AC-06.2 | Получить JWT, заблокировать пользователя, повторить запрос | Следующий запрос отвергнут |
| FR-03, NFR-03 | 5 файлов: поле отсутствует, дубль id, неверная дата, отрицательная сумма, неизвестный статус | Активная версия и контрольная сумма не меняются |
| AC-02.3 | Повторить успешный файл и параллельные загрузки | Один успешный hash, конфликт публикации виден, дублей нет |
| Восстановление | Убить worker при staging и после commit до подтверждения job | Нет частичной публикации, повтор не создаёт событие дважды |
| NFR-01 | 100 000 сделок, 10 пользователей, 2 vCPU/4 ГБ, холодный/тёплый кэш, отдельный прогон с импортом | p95 ≤3 с после применения фильтра, фиксировать длительность прогона и ошибки |
| Рост ПЗ №4 | 1 млн сделок, измерить RAM, SQL и импорт | Отдельный отчёт, ресурсы и согласованный SLO, не подмена NFR-01 |
| FR-05/06 | Экран и XLSX для одной версии/периода/scope | Совпадают значения, единицы, строки и общий итог |
| NFR-05 | Импорт, отказ, изменение ролей | Время/актор/результат есть, секретов нет |
| Отказ инфраструктуры | Отключить Redis, перезапустить API/worker, восстановить backup | SQL fallback корректен, версии согласованы, восстановление проверено |

Автономный пример паттернов: `python docs/architecture/examples/patterns_demo.py`. Он проверяет реальный rollback SQLite, commit и четыре формулы с Decimal, включая нулевые знаменатели.

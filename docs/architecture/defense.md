# Защита результатов: 5 минут

**0:00–0:40. Задача и драйверы.** Показываем назначение системы: четыре KPI вместо ручного объединения данных. Исходные требования: два участника, 100 000 сделок, p95 3 секунды, роли и отделы. Миллион строк является целевым расширением ПЗ №4.

**0:40–1:20. Стиль и контекст.** Выбрали модульный слоистый монолит. Четыре роли взаимодействуют с одной системой, CSV является обязательным источником. 1С и SMTP обозначены как будущие интеграции. Общая кодовая база сокращает трудозатраты команды.

**1:20–2:10. Контейнеры.** UI обращается к FastAPI, API проверяет JWT и актуальные права. API и worker используют один образ. PostgreSQL хранит сделки и задания, Redis только ускоряет, S3 хранит файлы. Логические Auth/KPI/Import/Reports остаются модулями.

**2:10–3:00. Компоненты и паттерны.** Контроллеры вызывают сервисы, сервисы используют порты. Repository скрывает SQL, UoW публикует данные атомарно, Strategy рассчитывает четыре KPI. Демонстрируем рабочий пример и null при отсутствии знаменателя. DTO отделяет API от ORM.

**3:00–3:50. Развёртывание и надёжность.** Внешний порт только HTTPS Nginx. Данные и хранилище находятся в закрытой сети с постоянными томами. Worker пишет staging и меняет активную версию только после полной проверки. При отказе Redis читаем PostgreSQL. Backup находится вне облачного узла.

**3:50–4:35. ADR и компромиссы.** ADR фиксируют стиль, PostgreSQL, JWT с отзывом, кэш и фоновые операции. JWT не заменяет проверку active/auth_version. Один узел не даёт высокой доступности, ресурсы и 3 секунды требуют измерений.

**4:35–5:00. Итог и развитие.** Показываем README, ссылки на диаграммы и PR. CSV/дашборд предшествуют XLSX и целям. Следующий шаг разработки: реализовать сценарии и выполнить план испытаний. Презентация содержит 7 слайдов в том же порядке.

## Вопросы на защите
- Почему не микросервисы? Два участника и общий релиз, стоимость распределённых операций сейчас не оправдана.
- Как исключаем частичный импорт? Невидимый staging и одна транзакция переключения version_id.
- Как отзыв JWT срабатывает сразу? Проверка active/auth_version в БД на каждом запросе.
- Почему нельзя усреднить конверсию отделов? Отделы имеют разные знаменатели, итог рассчитываем из общих won/lost.
- Как доказаны 3 секунды? Пока это цель, доказательством станет нагрузочный протокол из verification.md.

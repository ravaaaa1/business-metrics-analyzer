Диаграмма находится в use_case_diagram.puml. Формат .puml прямо разрешён заданием. Акторы: коммерческий директор, менеджер по продажам, аналитик, администратор системы. Ассоциации показывают участие акторов. Авторизация является предусловием, поэтому включение «Вход» через include в каждый сценарий не используется. UC-10 обозначает будущий мобильный способ выполнения UC-01 и вынесен за текущий релиз.

## UC-02. Загрузка данных о продажах

| Поле | Значение |
|---|---|
| Цель | Получить проверенный набор для расчёта KPI |
| Актор | Аналитик |
| Связь | US-02, FR-03, BR-01, BR-02 |
| Предусловия | Активная сессия аналитика, CSV подготовлен по схеме |
| Триггер | Аналитик выбирает «Загрузить данные» |
| Основной поток | 1. Выбирает CSV. 2. Отправляет файл. 3. Система проверяет заголовки, типы, уникальность и значения. 4. Система атомарно заменяет активный набор. 5. Фиксирует аудит и время версии. 6. Показывает количество импортированных сделок. |
| Альтернатива A1 | Ошибка в строке: файл целиком отклонён, аналитик видит номер строки и причину, прежний набор сохраняется. |
| Альтернатива A2 | Уже загруженный файл: система сообщает о повторе, набор и KPI не меняются. |
| Исключение | Сбой записи: транзакция отменяется, активным остаётся прежний набор, показано сообщение о неудаче. |
| Постусловие успеха | Новый набор доступен расчётам в разрешённых областях |
| Постусловие неудачи | Предыдущая версия данных остаётся активной |

## UC-04. Формирование отчёта

| Поле | Значение |
|---|---|
| Цель | Получить сравнимые KPI отделов за период |
| Основной актор | Аналитик |
| Другие акторы | Директор, менеджер в пределах своего отдела |
| Связь | US-04, FR-05, BR-04 |
| Предусловия | Пользователь авторизован, данные успешно загружены |
| Триггер | Пользователь открывает раздел отчётов |
| Основной поток | 1. Выбирает отчёт по отделам. 2. Указывает начальную и конечную даты. 3. Выбирает разрешённые отделы. 4. Нажимает «Сформировать». 5. Система проверяет доступ и корректность периода. 6. Считает четыре KPI по каждому отделу и общий итог из исходных сделок. 7. Показывает таблицу, период и время загрузки. |
| Альтернатива A1 | Нет закрытых сделок: сообщение «Нет данных за выбранный период». |
| Альтернатива A2 | Конечная дата раньше начальной: сообщение об ошибке, расчёт не запускается. |
| Альтернатива A3 | Запрошен чужой отдел: отказ в доступе, данные не раскрываются. |
| Постусловие | Отчёт доступен для просмотра и последующего UC-05 «Экспорт в Excel» |
